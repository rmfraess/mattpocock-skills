# Game Design Interview

Load the `grilling` skill through the available skill-loading tool, one skill per call, and follow its rounds, frontier, recommendations, fact gathering, and user decisions.

For game-design questions, ask only about the player's intended experience, interaction or camera, relevant references, constraints, and acceptance. Clarify the requested decision and the bounded next step it needs. Explore the broader design when the user asks for it, and keep other material unknowns visible rather than blocking a useful experiment on the whole game's design.

A choice made for an experiment can be provisional. State what is agreed now, what remains unknown, and what the smallest useful experiment would test; a prototype recommendation does not establish approved production direction. This entry point keeps outcomes in conversation and does not write project documentation or change Editor state. For a follow-up experiment or live project operation, read [the game-development working guidance](../GAME-DEVELOPMENT.md) and follow its existing scope and Editor-ownership rules.
