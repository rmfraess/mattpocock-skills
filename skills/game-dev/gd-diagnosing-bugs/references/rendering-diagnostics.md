# Rendered-artifact diagnosis

Use for speckling, streaks, unexpected darkness, aliasing, or other image defects. This is an evidence recipe, not a prescribed rendering fix.

## 1. Establish the exact reproduction

Record project/world, rendering path, camera transform, horizontal FOV, output dimensions, exposure, and relevant settings. Reuse supplied captures and source readback. When the user reports a symptom from their own session, read their live camera first (`UnrealEditorSubsystem.get_level_viewport_camera_info()`, and whether they were in PIE or the Editor viewport) and reproduce there before using your own review cameras: view direction relative to the sun and camera position relative to a volume can create or hide the artifact, so a clean metric at other cameras is not evidence against the report. For Unreal capture-path comparison, follow [native/offscreen captures](../../gd-implement/references/unreal-captures.md).

Compare the same pose through the native viewport before changing terrain or lighting. Record exposure separately for each path; identical numeric exposure inputs do not guarantee identical brightness. A cleaner native image can still contain the same defect. Inspect a matched full-resolution crop rather than relying on a resized panorama.

## 2. Design the discriminating probe

State a falsifiable prediction before changing a setting. Use the narrowest supported switch and identify what it actually disables: Unlit removes multiple lighting features; disabling Virtual Shadow Maps can enable conventional shadows. A change in either result narrows the cause but does not isolate every remaining contribution. High material roughness does not rule out a visible specular contribution at grazing road views; use a reversible specular-off control before changing roughness. Sun-off or sky-off with auto-exposure enabled measures the combined lighting/exposure response, not isolated light energy, and is not a production fix when route separation remains or shadow detail is lost.

For layered terrain, identify the exposed surface before interpreting a texture swap: trace candidate Landscape and detail/support components separately at the patch center and distributed offsets, choose the highest hit, and read that component's material override and the trial's spatial mask. A compiling material on the underlying Landscape cannot change a bank mesh above it. Distinguish a small patch's close-detail benefit from whole-view coverage; if several correctly sampled scans share the same washed-out road-eye result, test shared surface response/exposure or coverage rather than repeating asset, tint or density variants. Calibrate fixed exposure for readable ground before comparisons; a black calibration is not evidence. Under extended luminance range, a transient PIE camera with equal exposure min/max and neutral compensation supplies a bounded fixed-EV control without project writes. Measure the intervention against restored temporal drift and an unchanged road ROI; a few RGB levels or warmer close detail does not prove a useful road-eye fix. Label distributed ray/mask coverage as sampled coverage, not exact screen area.

Inspect material/actor readback for texture noise, displacement, visibility, and hidden-shadow behavior before attributing marks to unseen scene objects. For a surface that reads flat, paper-white or blown out, read the live instance parameters first (base colour above 1.0, normal intensity zeroed, detail tiling so small it averages out, a vendor material repurposed from another surface type): they explain the look without any lighting probe. For sharp-edged gaps in generated surface meshes, read the generator's triangle-rejection rule (support/ground tolerance) before suspecting rendering. Treat auxiliary image analysis as observations, not source authority: confirm algorithm names, object identities, and causal explanations against actual state. In Unreal, VSM means **Virtual Shadow Maps**.

Separate dark-pixel populations with actual shadow masks, BaseColor, normal and depth samples; a shadow switch can explain only part of the symptom. For UE Python float-depth readback, use an RGBA32F target with `SCS_SCENE_DEPTH` and `read_render_target_raw(..., False)`: the native helper supports RGBA float formats but not R32F, which can return None. Calibrate pixel-center mapping and depth against a known tilted transient surface, clean up in finally, and render extracted CPU collision as a transient DynamicMesh clone when distinguishing spline-render deformation from actual support intersections. A forced cache refresh that leaves depth unchanged does not isolate the precise shader math. Compare marked pixels to adjacent controls and decode buffers from their recorded formats. Populated material channels argue against completely unwritten GBuffer pixels; collision hits/normals do not prove equivalent rendered shading. SceneCapture buffer PNGs may have zero alpha despite valid RGB, and signed normals clamp in an 8-bit target: inspect RGB separately and use float/raw samples before declaring missing data. For a local native GPU dump, explicitly disable upload and explorer, restrict the root, verify completion, then restore every dump option.

For a subpixel join defect, measure the two adjacent native sections separately and compare each with its extracted CPU triangles in a small high-resolution orthographic window. Record world-units-per-pixel and depth precision; report sampled edge bounds rather than claiming exact GPU vertex positions. This separates a planar coverage gap from a vertical offset and identifies which section diverges, without a broad GPU dump. Then test the predicted counter-displacement on transient native clones before selecting a production correction; preserve the actual rendered path rather than crediting only an offline model.

## 3. Capture A → B → restored A

Within the authorized batch, change one variable, capture, restore its original value, then capture again. Use native session-only console commands when project configuration must remain unchanged. Restore in `finally`; stop the batch if restoration fails.

Bracket **each** capture with actual state readback, starting with the baseline: use `UnrealEditorSubsystem.get_level_viewport_camera_info()` for camera location/rotation and read the relevant FOV, exposure, selection and visibility values. Compare them with the intended pose before advancing to the next intervention; logging only the requested setter arguments misses input-driven drift. Keep pose, dimensions, exposure and capture path constant within each A → B → restored A triplet. Restore the tested variable before testing another group; restore exact prior visibility values rather than making every component visible. On an unexplained camera/selection change, restore only reconciled task-owned diagnostics, preserve the user's current view, pause Editor operations and resolve ownership instead of resetting the camera over possible user input. Discard confounded comparisons without treating them as evidence for or against a hypothesis. Check baseline/restored pixels before crediting a valid intervention; report temporal or brightness drift separately.

A single-frame offscreen capture may lack the native viewport's temporal state. Inspect the capture implementation and live properties before assuming AA/history equivalence. Warm a persistent transient capture across engine ticks, bound its callback, then remove its actor/callback/render target and verify inventory and dirty-state parity. Persistent view state changes exposure/pre-exposure: a readable one-shot input can export all-black warmed RGB. Inspect RGB extrema, calibrate only temporary-capture exposure within authorization, and disclose the mismatch; black frames are unusable, not artifact-free evidence. Read back the persistence flag and AA CVar without claiming those alone prove the active AA pass. An unchanged wide panorama does not prove close contact shadows are correct.

## 4. Analyze without inventing acceptance

With an already available image library, compare visible RGB using `ImageChops.difference(a.convert('RGB'), b.convert('RGB')).getbbox()`; check alpha separately when the claim includes it. An RGBA bounding-box check can inspect only alpha and miss RGB changes, especially in zero-alpha buffer exports. A null RGB bounding box establishes decoded color equality, not equal file bytes. If unequal, record changed-pixel bounds/count and inspect whether the delta reaches the symptom region. Report ROI parity separately from full-image parity; isolated edge differences do not justify silently changing a failed assertion to a pass.

Make a small labeled strip of corresponding crops, retaining the untouched full captures. Use nearest-neighbor enlargement when inspecting individual pixel fragments. Keep source hashes, actual capture-state readbacks and ROI definitions with task evidence. For a multi-location review sheet, label each panel as a different location in the same current saved scene, rather than implying before/after states or width alternatives. Ask image analysis for visible differences, not approval or a causal story; reject invented tree movement, road widening, route termination or shared-camera claims against the authentic source views. Obtain causal attribution from controlled interventions, not captions. Reject commentary that calls polygonal slivers shadows by assumption or says shapes match merely because the prompt described a fixed pose. Resolve contradictory descriptions using original captures, state readbacks and decoded-pixel/ROI comparisons; count the comparison as inconclusive when those controls disagree. Treat contact sheets as navigation aids, not independent proof.

If using an outlier metric, document ROI, neighbor rule, and threshold before comparing trials. Call the result diagnostic pixels, not numbers of defects or a substitute for visual acceptance. Partial clearing plus residuals proves a contribution only. An ineffective switch in one capture path does not prove the feature irrelevant in every runtime/temporal mode.

## 5. Close the bounded investigation

Apply the main skill's outcome/severity decision before extending the batch. Retain the distinct comparisons needed to explain the unresolved result and avoid repeating ineffective probes; retire completed next-step proposals from the current handoff.

Validate render-thread application before interpreting a visibility/material probe: a setter and immediate screenshot in one batched round-trip can capture stale state even with realtime enabled. Yield to Editor frames in a separate tool call, then confirm the intended object disappeared or recolored before crediting the comparison. Plain Engine materials assigned to spline meshes can auto-compile usage flags and dirty an Engine package; restore overrides and discard that unsaved package on clean shutdown, never save it as part of a scene fix. For a fine join seam, capture perspective road-only depth in the exact camera/ROI: absent road coverage differs from support winning depth. When the ROI includes exterior pixels, exclude them from support-overlap comparisons and require a minimum valid road-coverage count; never report them as road holes. Verify every intended support actor is present so an empty show-only list cannot produce a false pass. After lowering crossing support, recheck dense contact: clearing a strip can create excessive clearance just behind it, requiring a bounded face refinement rather than another broad lowering. An overlap-free top-down capture cannot clear a grazing-view crack.

When comparing source, render and cooked collision geometry, remap positions/faces before declaring topology different: cooking and render extraction can reorder vertex arrays. Validate analytic deformation against actual component extraction before using it to explain native GPU output. A simulated packed-scale or texture-frame model that does not reproduce the native defect is an unconfirmed model, not proof of the shader cause. A transient fresh-native-component control distinguishes reproducible native rendering behavior from stale component state without saving or replacing production assets.

For long native spline meshes, include packed mesh-axis quaternion decoding as well as spline-frame textures in a precision model. In UE5.8 the unsigned SNORM packing floors zero, so decoded identity axes can have small off-diagonal terms that multiply longitudinal mesh coordinates. Do not assume a frame-only model covers the shader: validate measured native/CPU edges and a transient counter-probe. A close model with residual mask/depth differences supports the dominant contribution, not bit-exact attribution or production acceptance. For an approved local correction, preserve mesh longitudinal bounds and native spline controls when they define the deformation interval; changing source length can refit the whole section. Prefer a measured terminal cross-section adjustment blended into the existing mesh, then prove cold grazing-view coverage and dense collision separately. Keep the rendered regression available independently when an unrelated route defect blocks the aggregate checker.

Read back every restored value, check package dirty lists and configuration parity, and preserve the fixed camera and unrelated assets. Deliver observed result, remaining uncertainty, and the next consequential decision in a few short lines. Keep successful diagnostic execution separate from feature completion and creative acceptance; carry untried approaches forward explicitly as proposals, not recommended fixes.
