# Native Landscape fixtures

Use for imported terrain, paint LayerInfo replacement and transactional editor tests. Inspect the installed engine signatures before adapting this recipe.

## Build a complete fixture

When a disposable project uses a plugin through `AdditionalPluginDirectories`, verify the Editor's `InternalLoadLibrary` path and the built DLL's test strings: UBT can write a project DLL while the Editor loads an older DLL from the source plugin. Prefer a task-local plugin copy and verify the changed source hashes match before crediting test results.

1. In a disposable non-World-Partition editor world, spawn a transient transactional Landscape and give it a unique label. Import terrain **before** calling `CreateLandscapeInfo` or creating spline components: eager registration can create a default edit layer with no component data, causing Import to skip initialization. A transient actor in a partitioned world may have no persisted actor descriptors; do not treat rejection by a partition-completeness guard as a behavioral failure or weaken the guard to accommodate it. Test partition behavior separately with a saved partitioned fixture.
2. Supply both import maps with the empty `FGuid()` key; the Landscape identity GUID is a separate argument. A small verified fixture is one subsection of 63 quads with 64×64 height samples and equally sized paint samples. Use a nonzero paint value and a named LayerInfo with explicit blend method so preservation cannot pass on empty data.
3. After `Import`, assert component/edit-layer counts and resolve the actual base layer GUID from `GetEditLayer(0)->GetGuid()`. Check `Component->GetLayerData(BaseGuid)` and its allocation count before indexing. Do not assume a default-layer count before import.
4. Read samples with `FLandscapeEditDataInterface(Info, BaseGuid)`. Keep authored edit-layer allocations separate from the rendered composite. A rendered allocation can legitimately be absent before a merge; leave it engine-owned. Never copy edit-layer allocation indices into rendered allocations without matching textures/usages: native validation dereferences those indices. Assert every allocated rendered texture index has backing storage.

## Exercise replacement and persistence

5. Test null assets, mismatched names, blend methods and effective blend groups, and an already-allocated destination before mutation; native replacement can otherwise merge weights or change advanced blend grouping. Exercise different physical materials and collision relevance thresholds too: swapping LayerInfo identities alone does not necessarily rebuild cached collision or its physical material selection. Verify component inventory in both directions: test both a component absent from the native lookup map and a mapped component absent from its proxy's inspected array, since the native replacement iterates the map. Compare all decoded height and weight samples before/after, and assert a known nonzero paint sample. Check a second Landscape remains untouched and the active edit layer is preserved.
6. Test repeat calls and Undo/Redo from a **consistent** pre-transaction target list. If that list already names the destination while allocations name the source, native post-Undo fixup can legitimately rebind restored allocations to the destination again. Treat partially rebound clone recovery as a separate condition, not a contradictory Undo expectation. Seed a nonempty reimport filename and assert both the LayerInfo identity and filename on the parent and a registered proxy after replacement, Undo and Redo: native replacement recreates the target settings and otherwise clears the path. Guard Undo behind a successful replacement so a failed positive control cannot undo an unrelated transaction.
7. Seed a source LayerInfo and an unrelated entry in the component's serialized layer allowlist; after replacement and after both Undo and Redo, verify source/destination identities and preserve the unrelated entry. Native allowlist refresh is additive, so updating paint allocations alone can leave a stale asset dependency. Also assert edit-layer, rendered, mobile and collision reference identities, plus counts where arrays may be empty. Checking only the edit-layer array misses incomplete restoration of serialized caches, and pointer equality alone does not verify live physical-material queries. Include paint/height preservation and, when physics can change, settled collision queries separately from identity checks.
8. When widening identifier scans to detect hidden duplicates, test both a visible duplicate and a single inactive-level target across lookup, existence, mutation and create/import paths. Preserve the prior active-level mutation boundary while preventing an unavailable match from being mistaken for absence: Unreal's default actor iterator excludes inactive levels, and removing that filter can silently expose them to every existing caller. Restore any temporarily changed fixture visibility before assertions or teardown.
9. For World Partition completeness, use a saved disposable multi-proxy Landscape and verify the live proxy count before invoking the public operation. Exercise one and all proxies unloaded, both while removed proxy objects remain resident and after garbage collection, alongside an all-loaded success control and an unrelated Landscape. To exercise the resident case in Editor Python, retain the target proxy wrappers on `unreal` before unloading, then assert those wrappers remain readable while `EditorActorSubsystem.get_all_level_actors()` excludes them; remove the retained references before changing worlds. Assert rejection preserves target references, allocations and the dirty-package baseline. A request to unload is not proof of unloading, and a fully loaded save/reload only proves that case. `IsLoaded()` can rediscover a resident actor removed from the world, so it and `HasUnloadedComponentsInRegion()` do not prove proxy registration. If a scripted unload does not change the live inventory, ask the Editor owner to select the loaded region in **Window > World Partition > World Partition Editor** and use **Unload Selected Regions**, then verify the inventory independently. For a repeatable partial-load check, record the fixture proxies' actor GUIDs while loaded, unload the region, use `unreal.WorldPartitionBlueprintLibrary.load_actors([one_guid])`, and assert exactly one target proxy is in the live actor list before testing; in `finally`, load the remaining fixture GUIDs and verify restoration. This is a partial-load test, not an automated unload or GC test. Alternatively reload the region through **Load Region from Selection**. Do not infer success from the UI action.
10. Add a stale-inventory regression in a disposable non-partitioned world: import a transient parent and an adjacent streaming proxy with real components, register both with the same LandscapeInfo, and verify their paint identities and component mappings. Hold a strong proxy reference, record its level-array slot and GC-list membership, then call `World->RemoveActor(Proxy, false)`. Assert the proxy is absent from the level but still in LandscapeInfo with registered components; replacement must reject and retain the source identities and parent's target. Reattach the proxy and require replacement to succeed: a false return alone could come from an unrelated preflight guard. Use scope-exit cleanup to restore the recorded level slot, GC-list and network membership before unregistering and destroying the proxy, even on assertion failure. Identity presence does not prove unchanged paint samples or allocation contents; compare those separately when claimed. This fixture tests inverse inventory, not World Partition descriptors; run the regression before and after the fix.
11. Destroy fixture actors without saving the host map and confirm dirty-state reconciliation. Only after the fixture passes, exercise the built service through its intended Editor interface on the authorized asset, then save/reload and inspect dependency closure and decoded terrain/paint. Check `target_layers` on the parent and each loaded streaming proxy individually, not just the parent-level layer listing; use `get_editor_property('target_layers')` and each setting's `layer_info_obj` to inspect reflected identities. Fixture success alone does not establish saved production correctness, and matching target maps alone does not prove closure of component allocations or caches. Check persisted package dependencies as well as loaded proxy values when dependency closure matters: registration or load-time shared-property fixup can mask a stale saved reference.

12. For edit-layer blend metadata, seed a source-only map key in an otherwise already-replaced fixture, then verify the key moves with both `true` and explicit `false` values, unrelated keys remain, repeat calls do not displace Undo, and Undo/Redo restores metadata. Test conflicting source/destination entries before any mutation and include a normal replacement control. UE 5.8 marks the exact map accessors `UE_INTERNAL`; type-checked reflection can seed and inspect the private map in a test fixture without treating that layout as a supported production API. The public native mover can overwrite a destination value, and its internal `Modify()` follows mutation, so preflight conflicts and snapshot affected transactional edit-layer objects before calling it.

13. For an unsupported-custom-layer guard, first look for a suitable existing class; avoid adding an external plugin just for the fixture. If none exists, a private test subclass of `ULandscapeEditLayer` can be declared reflection-abstract so the Landscape class picker excludes it, while implementing the engine's actual virtual behavior; use `FScopedAllowAbstractClassAllocation` only around its `CreateLayer` call and only when the C++ implementation is complete. Inspect the installed engine headers and exports: in UE 5.8's modular build, `SupportsTargetType` and `GetRenderFlags` require local overrides because their base implementations are not exported. Create and delete the layer through `ALandscape`, clean it up by GUID on every exit, and use a disposable world because setup schedules layer updates. Seed source blend metadata and snapshot paint, target, caches and other references after setup; assert rejection preserves them before cleanup, then require replacement to succeed on the same fixture without the custom layer. Confirm the oracle with a disposable mutation that changes metadata before rejection. This exercises one subclass, not every third-party implementation.

14. For attached Blueprint brush references, use the imported, nonzero-paint fixture and spawn a transient, transactional concrete `ALandscapeBlueprintBrushBase` subclass with a reflected LayerInfo pointer. Set it to the source and attach it with `ALandscape::AddBrushToLayer`; assert the standard edit-layer class, brush membership and owning Landscape before calling replacement. Verify the target, brush reference, allocations, allowlist, height and paint after rejection, then remove the brush and require success on the same fixture. Use scope-exit cleanup to remove the brush before destroying it. Against an unsafe implementation, verify the actual failure is success with a stale brush reference and Undo that unexpected success; do not count setup or compilation failures as behavioral red. A native test subclass proves the attached-actor reference path, not every Blueprint-generated class or indirect reference.

## Landscape Patch integration

In a rendering-capable disposable project with Epic's Landscape Patch plugin enabled, save a non-partitioned Landscape and distinct compatible source/destination LayerInfo assets. Paint two weight-blended layers with nonzero weights: a single normalized layer can read as fully weighted everywhere and hide a weight patch's contribution.

Add a real `LandscapeCircleHeightPatch` and `LandscapeTexturePatch` to a placed actor using `SubobjectDataSubsystem.add_new_subobject`; verify each component's Landscape and edit-layer binding. Adding the first patch can automatically create its edit layer and open a blocking insertion dialog; inspect the Editor window and actual Python outcome after a timeout instead of retrying the add. Set the height patch over an interior point. Set texture-patch coverage and resolution, call `create_weight_patch` for the paint layer with `TEXTURE_BACKED_RENDER_TARGET` and alpha mode `NONE`, obtain its target with `get_weight_patch_render_target`, clear it to a known value, and request a Landscape update.

After the editor settles, compare a center and outside sample with the patches enabled, then disable them, request another update and sample in a later call. Re-enable them and establish a nonzero effect before testing replacement: an existing layer or component alone does not prove it influences the result. Read authored base weights separately from the settled merged paint using `LandscapeComponent.editor_get_paint_layer_weight_by_name_at_location`; a base-edit-layer region reader does not measure procedural paint. Compare both base and merged samples and the height sample across rejection or replacement, Undo and Redo. Save only the disposable fixture, load another map, reload and reacquire the actors; check target identity, patch bindings, samples, disable/re-enable effects, and saved source/destination package referencers. A passing built-in-patch fixture does not prove arbitrary custom patch components or external references safe.

For a focused negative probe, create a transient Python `@unreal.uclass()` subclass of `LandscapeCircleHeightPatch` with `unreal.uproperty(unreal.LandscapeLayerInfoObject)`, add it through the subobject subsystem to a disposable actor, and verify its binding to the actual patch layer. Set and read back the property pointing at the old LayerInfo before calling replacement; check both the Landscape target and the component property afterward. A changed target with the old component reference demonstrates incomplete reference repair. Run the same guard check with the custom patch enabled and disabled: disabling its effect does not clear its asset reference. Require the intended failure against the unsafe variant and a positive control with built-in patches on the same fixture, so an unrelated refusal cannot masquerade as protection. Undo any successful test operation, release Python references, discard the unsaved fixture map, reload its saved version, and verify the transient component is absent. Python-generated classes are transient: this probe is not a save/reload test for a persisted custom component.
